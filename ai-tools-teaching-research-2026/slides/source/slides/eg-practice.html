Questions stay hidden until you share them

How to share them

  1. On the Questions page, click Send to Practice
  2. Choose Create new, give it a name, click Add
  3. Go to Modules, not the lesson
  4. On the module card, click Add practice
  5. Check it with Preview as Student

Students see

Slides, study guides, worksheets, and practice sets added to a module

Students don’t see

Lesson plans, and questions not yet in a practice set

Practice sets are ungraded and send no grades to the LMS; graded work goes in Quizzes

This tripped us up. We created the practice set, but it was marked unshared and did not appear in the lesson. The lesson’s Attach existing resource list has no practice sets: they attach at module level, with the Add practice button on each module card. Always confirm with Preview as Student.
