Step 3 · The one setting to watch

Generate one content type at a time

The Generate panel opens with Select All ticked: lesson plan, slides, questions, study guide and worksheet. Untick it, pick one, check the result, then go on.

This is where credits disappear. Clicking Generate on a lesson opens a panel with all five content types selected. Even after unticking Select All, some tiles can stay selected, so look at which tiles are highlighted before you click Generate. Start with slides for one lesson, review them, then repeat.
