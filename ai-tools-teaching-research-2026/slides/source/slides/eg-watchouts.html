Five things to watch

Browser autofill. Sakai’s External Tool form filled in a saved login as the key and secret. Clear it and cancel.

The access code is a key. Anyone who has it can load your course. Share it privately; regenerate it if it leaks.

Empty modules show. Use “Hide from learners” on any module that isn’t ready before you publish.

The default AI model isn’t disclosed. Ask support@edugears.ai before students use the AI Tutor.

Free API keys may train on your data. Use a paid key for anything students touch.

EduGears AI Studio · worked example

Each of these happened, or nearly happened, in our build. The autofill one matters most: if that form had been saved, a password would have been sent to an outside service on every launch. On the model question, EduGears’ public pages and privacy policy name no AI provider, so check before any student data flows.
