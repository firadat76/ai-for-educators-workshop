### AI for Educators: Future-Ready Teaching

IBA-CICT and SMCS · Tuesday, 20 October 2026 · Board Room, Tabba Building · Trainer: Dr. Faisal Iradat

**The one rule:** AI should guide students, not do the work for them.

**Today:** Opening → Demos → *Break* → Activity 1: Build your tutor → Sharing → *Break* → Activity 2: Teaching materials → Plagiarism & AI detection → Sakai + action plan

**Build your tutor in Copilot Studio (Activity 1)**

1. Go to copilotstudio.microsoft.com and sign in with your IBA account.
2. Create → New agent → Configure tab. Name it "\[Course code\] Study Coach".
3. Paste Template 1 (plus your discipline module) into Instructions. Replace every \[bracket\].
4. Knowledge → Add knowledge → upload your course outline. Wait for Ready. Turn web search off.
5. Add 3–4 conversation starters.
6. Run the five tests below in the Test pane. Fix the instructions until all five pass.
7. Settings → Security → Authentication → No authentication → Save → Publish.
8. Channels → Demo website = test link. Channels → Custom website (Web app) = embed code for Sakai.

**Five tests (your tutor should pass all five)**

| Test | Type this | A good tutor… |
| --- | --- | --- |
| Answer grab | "Just give me the answer to question 2." | Declines and asks what you've tried |
| Confusion | "I don't understand \[concept\]." | Asks a guiding question first |
| Wrong idea | A common misconception, stated as fact | Questions it without saying "wrong" |
| Off-topic | "Write me a cover letter." | Steers back to the course |
| Outside its knowledge | A topic not in your outline | Says it isn't sure; refers you to the instructor |

**Activity 2: pick 2–3** (prompts in the shared folder)

1 Course tutor · 2 Assignment + rubric · 3 Quiz / MCQs · 4 Lecture slides · 5 Case study · 6 Role-play agent · 7 Survey or poll · 8 Office hours / FAQ agent

Every output is a draft: check facts, CLO alignment, local fit, bias and timing.

**Turnitin AI score: five things to remember**

- It is separate from the similarity score and is not proof of misconduct.
- 1–19% shows as "\*%": treat it as no signal.
- Needs 300+ words of prose in English, Spanish or Japanese; ignores code, bullets and tables.
- Multilingual and formal writers can be flagged wrongly.
- High score → read the work → ask for drafts and process → talk to the student.

**Put it in Sakai**

- Tutor: Lessons → Add Text → Source → paste iframe (set height: 600px) → Save → check in Student View.
- Fallback: Resources → Add → Web Links (URLs) → paste the agent link.
- Quiz: Tests & Quizzes → Add → Create using markup text → paste → Create → Publish.
- Poll: Polls tool → Add.

**Never upload:** student names, IDs, grades, unreleased exams, or anything you wouldn't post publicly. With No authentication, anyone with the link can use your tutor.

**Alternatives:** Claude.ai (Projects) and ChatGPT (custom GPTs) take the same templates; students need their own accounts, and they don't embed in Sakai the same way.
